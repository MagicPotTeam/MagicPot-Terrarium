1. 在画布右侧打开普通 Agent 会话，通过输入框的「+」菜单选择组建团队或添加成员。
2. 设置成员名称和角色；在进程区查看成员，点击成员名称进入其对话，或使用标题行的「⋯」打开团队管理。成员未单独选模型时继承组长；团队设置的默认模型菜单目前只允许继承或选组长当前模型。若创建提示“结果未确认”，先核对原团队成员；没有记录也不能证明未创建，未确认前勿重复创建。当前工作树对 `AgentTeamMemberForm.errorAlert.test.tsx` 与 `AgentTeamTree.test.tsx` 定向复跑为 **2 文件20/20**，`AgentTeamTree.tsx` 与两测试 scoped quiet ESLint exit0、3个目标限定 Web TS diagnostics 0、目标 diff-check exit0；证据仅为 DOM/jsdom/fake onCreate，不锁定创建按钮、不提供防重，也不证明真实创建结果、列表核对、读屏或桌面生命周期。
