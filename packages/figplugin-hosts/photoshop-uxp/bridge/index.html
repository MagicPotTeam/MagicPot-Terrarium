      Recovery sends the freshly selected task context only to the paired desktop, not a model.
      Select the exact accepted target set. Desktop approval is still required. Only accepted task
      properties are restored; other edits are preserved. Accepted image content and placement can
      be restored after reload or restart from encrypted saved source bytes, with a fresh preview
      and approval. Recovery verifies the full canonical pixels before and after the write; it does
      not call a model or publish saved images to the local-preview catalog.
    

    

      Native planning requires a complete selection of 1–100 active layers. It captures only
      properties declared executable by this host. Sharing needs explicit consent; model output
      still requires a separate desktop write approval before any document change.
    

    

      Image writes require a separate exact desktop write approval and a claim-bound image read;
      local preview and planning metadata never grant write permission. image.pixels replaces all
      pixels of an existing selected pixel layer at its captured position, with the image's native
      dimensions: no resizing and no partial-region patch. Only unlocked, non-background,
      non-clipping RGB / sRGB / 8-bit layers with no pixel selection and all component channels
      active qualify. Bounds must fit the canvas. The 128 MiB plugin pixel-buffer budget allows at
      most 8,388,544 pixels per image including hash-buffer overhead, and may reject combinations of
      images. This is not a bound on Photoshop's own document or decoder memory.
    

    

      Approved execution decodes only its authenticated bytes through a private temporary file and
      owned Photoshop document, then releases them. Full-resolution observed sRGB RGBA is checked
      independently: trimmed transparent margins are padded, RGB is expanded and RGB under zero
      alpha is ignored. This does not certify Photoshop's hidden raw pixel storage. A failed image
      plan uses an owned native history transaction only while its history is unchanged; later edits
      are not overwritten. Recovery keeps the accepted destination separate from this attempt's
      fresh native rollback baseline. Unverifiable results remain unknown. Automatic image
      correction is not supported; bounded thumbnails are not image backups.
    

    

      Metadata-only capture reads the first 100 active layers. Capture again to replace that
      snapshot and cancel any pending review. Image capture instead requires exactly one selected
      layer and invalidates when observed document, selection or host state changes.
    

    

      Image capture is local and explicit: one PNG, at most 256 pixels per edge and 24 KiB. Native
      imaging, change observation and exact image decoding must be available; otherwise choose
      metadata capture. No file is saved and no image is sent in the background. Share locally
      rechecks the same captured image before sending only the original preview for separate desktop
      approval. A changed or failed image requires a new capture and new consent.
